# وب‌سایت محمدجواد عرفانی

وب‌سایت فارسی رسمی با پنج صفحه، تصاویر اصلی، لینک‌های تلگرام، اینستاگرام، یوتیوب، اسپاتیفای و نمایهٔ گوگل.

- دامنهٔ اصلی: https://mjerfani.nx.kg/
- کد کامل و تصاویر: `MJErfani_GitHub_Website.zip`
- انتشار خودکار: `.github/workflows/deploy.yml`

## انتشار و ویرایش

GitHub Actions بسته را باز می‌کند، HTML و فایل‌های سئو را تولید و بررسی می‌کند و فایل‌های عمومی سایت را در GitHub Pages منتشر می‌کند. در Settings → Pages، منبع انتشار باید GitHub Actions باشد.

برای ویرایش، ZIP را باز کنید و داخل پوشهٔ `mjerfani-site`، اطلاعات مشترک را در `site.json` و متن‌ها را در `tools/build.py` تغییر دهید. برای بررسی محلی، `python3 tools/build.py` و `python3 tools/check.py` را اجرا کنید. پوشهٔ `mjerfani-site` را دوباره با همان نام ZIP بسته‌بندی و در ریشهٔ مخزن جایگزین کنید. اجرای موفق Actions تغییر را منتشر می‌کند.

راهنمای دامنه، Search Console، تصاویر و گزارش سئو داخل بسته قرار دارد. مقصد DNS این حساب `istaism.github.io` است، بدون نام مخزن. ثبت دامنه در تنظیمات Pages جداگانه انجام می‌شود.

ایندکس و رتبهٔ گوگل تضمین‌شدنی نیست. برای ثبت نقشهٔ سایت، پس از تأیید مالکیت در Google Search Console نشانی `https://mjerfani.nx.kg/sitemap.xml` را ثبت کنید.
